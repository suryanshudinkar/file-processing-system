File Processing System
This is a File Processing System designed to process files of various formats such as CSV, JSON, and XML. It includes logging capabilities, handles file processing in chunks, and provides detailed audit logs of each operation. The system tracks the processing of files, logs the status of each operation (success or failure), and generates output files based on the processed data.

Features
Multi-format support: Processes CSV, JSON, and XML files.
Audit Logging: Logs the start and end times of file processing, along with the status (success or failure) and any error details.
Chunked File Processing: Efficiently processes large files in chunks to reduce memory usage.
Processing Summary: Generates a summary of the processing, including the number of successful and failed records.
